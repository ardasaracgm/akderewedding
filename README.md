# Akdere Wedding Website

Next.js + Tailwind CSS ile hazırlanmış tek sayfa Akdere Wedding web sitesi.

## Kurulum

```bash
npm install
npm run dev
```

## Yayına alma

1. Bu klasörü GitHub reposuna yükleyin.
2. Vercel hesabınızda **New Project** seçin.
3. GitHub reposunu bağlayın.
4. Deploy edin.

## Görseller

Tüm görseller `public/images/` klasöründedir. Yeni görsel eklemek için aynı klasöre koyup `app/page.tsx` içindeki yolları güncelleyin.
